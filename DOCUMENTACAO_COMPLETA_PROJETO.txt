CYBERKIDS ARCADE: DOCUMENTAÇÃO TÉCNICA

A documentação canônica atual está em README.md.
O relatório de validação e suas limitações está em docs/VALIDATION.md.
Os achados da revisão estão em docs/audit.json.
O estado da tarefa e os passos de retomada estão em STATUS.json.

Arquitetura: site estático com cinco jogos, sem banco de dados remoto.
Perfil: profile.js concentra o schema, recordes, medalhas e fallback local.
Inspector: dez rodadas de classificação de endereços simulados.
Detector de Fakes: dez notificações com explicação de cada resposta.
Chat Patrol: cinco turnos, onze contatos, cruzamento de pistas, bloqueio seguro
imediato e leitura sem limite de tempo.
Senha Secreta: seis missões com palavras fornecidas para treino.
Escudo de Privacidade: seis cenários usando um perfil fictício.

Para iniciar: npm start
Para verificar: npm ci; npx playwright install chromium; npm test
O site abre em http://127.0.0.1:8765.
Não existe compilação obrigatória nem dependência externa para jogar.

Publicação: servir os arquivos estáticos pelo GitHub Pages ou outro servidor.
O pedido atual prepara a cópia local. Consultar STATUS.json para saber se houve
publicação; alterações em disco não comprovam atualização do site público.

As versões anteriores deste documento estão preservadas no histórico Git.
